# 能力总览

> 本文是烛夜的能力说明与已知边界。快速上手见根目录
> [README](../README.md)；引擎内部怎么搭见
> [architecture.md](architecture.md)。

## 嵌进自己的产品

同一套 Rust 引擎有三种用法：直接链接进你的进程、跑一轮就退出、或者维持一个会话服务让客户端连上来。引擎是库，不是产品。

## 工具留在你自己的进程里

你在 Python 或 TypeScript 里写的函数，不用改写成 Rust。注册个名字和参数格式，模型要用的时候引擎把请求发回你的进程，函数跑完把结果回执。

## 多 agent 是原语，不是插件

子代理、角色讨论、声明式的任务流水线、任务与团队，都是引擎自带的编排能力，不用先装什么扩展。

## 换模型不用重写提示词

每家模型有各自的脾气，内置提示词按「默认 → 厂商 → 具体模型」分层叠好，换模型自动换用适合它的那套文案；还能配一条候选链，某个 provider 挂了自动换下一个。

## 上下文自己会收拾

快到上限时先在本地裁剪，实在压不下去才叫摘要模型重写一遍；压缩完再把还活跃的文件读回来。

## 危险操作有闸门

权限模式决定哪些操作要问你、哪些直接放行、哪些直接禁止；hooks 能在工具执行前后改参数、拦调用、插话；`bash` 默认跑在系统沙箱里（macOS 用 Seatbelt、Linux 用 Landlock），沙箱起不来就直接失败，不会偷偷退回裸 shell。工具、hook 事件、权限模式与沙箱的字段级说明见 [tools-and-hooks.md](tools-and-hooks.md)。

## 每次会话都留档

全过程写成 JSONL，随时回看、接着跑、分叉出新分支、跨会话搜索，还能导出成带用量统计的 Markdown。

## 会话之外也有抓手

`memory` 工具让模型把经验写进跨会话记忆；side-channel 让用户发起的并发 agent 与主轮次并行互不干扰；cron 任务跨重启持久化；每轮结束落一条操作审计（Activity），谁在何时做了什么可回查。

## git 是一等公民

内置 checkpoint / rewind（打 tag 的快照，回退之后依然可达）；插件再加分支 / PR 探测和每轮自动快照。

## 边界与限制

- 这个仓库的二进制没有 TUI 子命令。交互界面在 [Reflect-TUI](https://cnb.cool/Demon1019/Reflect-CLI) 仓库。
- 沙箱在 macOS 上默认断网，Linux 上只限制写、不切网络。
- 同一个会话里同时在途的子代理最多 16 个，子任务结束就释放名额。
